Setup Guide (App Owner ke liye)

  1. Is file ke code mein JAZZCASH_NUMBER variable mein apna JazzCash mobile number daalein.
  2. emailjs.com par free account banayein (bina backend ke email bhejne ke liye).
  3. EmailJS dashboard se apni Service ID, Template ID, aur Public Key copy karein.
  4. Code mein EMAILJS_SERVICE_ID, EMAILJS_TEMPLATE_ID, aur EMAILJS_PUBLIC_KEY variables mein paste karein.
  5. EmailJS template mein {{tid}}, {{sender_email}}, {{sender_number}} fields use karein taaki details email mein aayein.
  6. console.firebase.google.com par free project banayein, phir Firestore Database enable karein (test mode se shuru karein).
  7. Project Settings → General → "Your apps" → Web app add karke apna Firebase Config object copy karein.
  8. Code mein FIREBASE_CONFIG variable mein poora config paste karein — isse unlock status save aur persist hoga.
  9. Kisi user ka request approve karne ke liye: Firebase Console → Firestore → proRequests collection kholein, us document ka status field "pending" se "approved" karein. Reject karne ke liye "rejected" karein.

⚠️ Security note: is system mein koi real payment verification nahi hai — koi bhi fake Transaction ID daal kar unlock kar sakta hai. Yeh sirf tab tak theek hai jab tak scale chhota ho aur aap manually TID ko apne JazzCash app/statement mein check karte rahein.
